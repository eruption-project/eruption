# Shell SDK Flows

These examples demonstrate practical shell automation around Eruption.

## Flows

- `connect_and_query.sh`: connect/query flow (profile, slot, brightness)
- `update_state.sh`: update flow (slot + brightness)
- `error_handling.sh`: error-handling flow with recovery behavior

## Run

From repository root:

```bash
bash sdk/examples/shell/connect_and_query.sh
bash sdk/examples/shell/update_state.sh 2 70
bash sdk/examples/shell/error_handling.sh
```
