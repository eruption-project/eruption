# Eruption KDE Plasma Widget Template

This is a starter template for a KDE Plasma widget that integrates with Eruption.

## Template Contents

- `metadata.json`: widget metadata
- `contents/ui/main.qml`: basic UI shell with placeholder actions

## Next Steps
